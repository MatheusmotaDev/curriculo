# Currículo e Portfólio

Site pessoal criado com React e Next.js para apresentar minha formação,
experiências profissionais, projetos e tecnologias.

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o projeto:

```bash
npm run dev
```

3. Abra `http://localhost:3000` no navegador.

## Páginas

- Home
- Sobre
- Experiência acadêmica
- Experiência profissional
- Projetos desenvolvidos

## Tecnologias usadas

- React
- Next.js
- CSS
- BrasilAPI para consultar feriados nacionais
